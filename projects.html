Kirchhoff's Circuit Solver

Comprehensive Overview:

Designed and coded as a scientific computation project combining Linear Algebra and Electrical Circuit theory. The application accepts complex multi-loop circuit configurations with voltage sources and resistors, formulates loop/mesh equations using Kirchhoff's Voltage Law (KVL), and solves the unknown loop currents using Gauss-Jordan matrix reduction algorithm implemented in Python.


Key Features:

  • Step-by-step matrix reduction output for academic verification.
  • Handles arbitrary N-loop linear electrical networks.
  • Precision floating-point error handling and validation.
